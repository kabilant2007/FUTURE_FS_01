## Color Scheme

### Light Mode
```
Primary:      #0a66c2 (LinkedIn Blue)
Secondary:    #00a8e0 (Cyan)
Accent:       #ff006e (Pink/Red)
Background:   #ffffff (White)
Text:         #1a1a1a (Dark Gray)
```

### Dark Mode
```
Primary:      #0a66c2 (Stays same)
Secondary:    #00a8e0 (Stays same)
Accent:       #ff006e (Stays same)
Background:   #0f1419 (Dark)
Text:         #ffffff (White)
```

## Contact Form Flow

```
User Fills Form
        ↓
Validation (Frontend)
        ↓
Submit to Backend
        ↓
Backend Validation
        ↓
Send Emails
        ├─ Admin Email (New Contact)
        └─ User Email (Confirmation)
        ↓
Success Message
```
